# 39 ricette nuove (61 → 100) — piano dei contenuti

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Portare Cucinança da 61 a 100 ricette con 39 ricette nuove già dotate di sostituti, prompt foto e foto generate, aggiornando tassonomia e documentazione.

**Architecture:** Le ricette vivono in `data/ricette/{primi,secondi,piatti-unici,contorni,dolci}.json` (array JSON per categoria), validate da `scripts/build-data.mjs` contro `schema/recipe.schema.json` e `data/ingredienti.json`, e fuse in `data/recipes.json`. Le foto si generano con `scripts/generate_image.py` (Gemini) dal campo `foto.prompt`, poi `scripts/optimize-images.mjs` produce `img/<slug>.webp`. `prompts.md` si rigenera con `npm run prompts`.

**Tech Stack:** JSON, Node 24 (`npm run build:data`, `npm run prompts`, `npm run images:optimize`), Python 3 + `google-genai` (`python scripts/generate_image.py --all`, chiave `GEMINI_API_KEY` in `.env`).

**Spec:** `docs/superpowers/specs/2026-09-11-cucinanca-100-ricette-design.md` (§4 ricette, §5 foto, §6 docs). **Prerequisito:** il piano `2026-09-11-sito-condiviso-sostituzioni-i18n.md` completato (schema `sostituti`, niente vietati, `npm run prompts` esistente).

## Global Constraints

- Ogni ricetta è **dosata per 1 persona** (`porzioni: 1`), prezzi a Bragança (`costo.stima_eur` ≤ 10; fasce: `basso` ≤ 3 €, `medio` 3–6 €, `alto` 6–10 €).
- Niente frattaglie. Peperoncino ammesso, sempre dosabile (nota "dosabile" o "opzionale" nell'ingrediente). Pomodoro crudo ammesso.
- Il validatore impone: `veloce` se preparazione+cottura ≤ 30′; `weekend` se > 45′; `qb` ⇒ `qta: null`; ogni altro ingrediente con `qta`; `foto.copertina` = `img/<slug>.webp`; `procedimento[].n` progressivi da 1; `sostituti[].id` esistenti, non `base`, non l'ingrediente stesso, mai su ingredienti `opzionale`.
- Ingredienti `base` (sempre in casa, non contano nel matching): `olio-evo, sale, pepe, aglio, cipolla, burro, farina-00, zucchero, aceto, limone, brodo, parmigiano, alloro, rosmarino, paprika-dolce, curry, basilico, coriandolo`. Vanno comunque elencati con le quantità quando servono.
- Id ammessi: solo quelli in `data/ingredienti.json` (elenco: `node -e "console.log(require('./data/ingredienti.json').map(i=>i.id).join(' '))"`). Un ingrediente che manca si aggiunge in tassonomia (Task 1), non si inventa nella ricetta.
- Voce: seconda persona, diretta, pratica, un tocco di ironia asciutta ogni tanto. Niente "delizioso", niente punti esclamativi, niente elenchi di aggettivi. I passi dicono cosa fare e cosa vedere/sentire ("deve sfrigolare", "quando il fondo è dorato").
- `foto.prompt` in inglese, solo la descrizione del piatto impiattato (lo stile lo aggiunge lo script): 15–35 parole, piatto/ciotola bianchi, niente mani, niente testo.
- `data/recipes.json` e `prompts.md` sono generati: si committano insieme ai sorgenti.
- Ogni task finisce con `npm run build:data && npm test && npm run prompts` verdi e un commit. Messaggi in italiano, chiusi da:
